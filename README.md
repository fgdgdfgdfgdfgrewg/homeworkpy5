# Проект: Обработка финансовых транзакций

Проект предназначен для обработки данных о финансовых транзакциях из различных источников.

## Новая функциональность: Поддержка CSV и Excel форматов

Теперь приложение поддерживает чтение финансовых транзакций из CSV и Excel файлов. Реализованы две новые функции:

### `read_csv(file_path: str) -> List[Dict[str, str]]`
- **Описание**: Считывает финансовые операции из CSV-файла
- **Параметры**:
  - `file_path`: Путь к CSV-файлу
- **Возвращаемое значение**:
  - Список словарей, где каждый словарь представляет одну транзакцию
  - Ключи словаря - названия столбцов из файла
  - Все значения преобразуются в строковый тип
- **Особенности**:
  - Используется разделитель запятая (`,`) 
  - Поддерживает поля в кавычках
  - Автоматически определяет заголовки столбцов
- **Пример использования**:
  ```python
  from src.file_handlers import read_csv
  
  transactions = read_csv("data/transactions.csv")
  for transaction in transactions:
      print(f"ID: {transaction['id']}, Amount: {transaction['amount']}, Date: {transaction['date']}")
